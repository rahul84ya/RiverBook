# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/rahul84ya/RiverBook.git
```

## 2️⃣ Move into the Project Folder

```bash
cd RiverBook
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
